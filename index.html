    Quick start

    Download Robot SDK 1.5.0 for your platform and extract the full archive. Run the commands below from the extracted package directory.

    Robot SDK for Windows x641.5.0 · MSVC 2019 v142 · ZIP↓ Robot SDK for Linux x86_641.5.0 · GCC · TAR.GZ↓

    Downloading or using this SDK is subject to the SDK Software License. Download license (TXT)

    Python

    Choose a wheel from bindings/python/ matching your CPython version. This example uses 3.10 on Windows.

    python -m pip install "./bindings/python/robot_sdk-1.5.0-cp310-cp310-win_amd64.whl"
python -c "from robot_sdk import Robot; print('Robot SDK import OK')"

    Bundled wheels: Windows 3.9–3.12 · Linux 3.9–3.13.

    C++ C++17 · CMake 3.21+

    Build the packaged examples. Set CMAKE_PREFIX_PATH to the extracted SDK root.

    cmake -S examples/cpp -B build -DCMAKE_PREFIX_PATH="<sdk-root>"
cmake --build build --config Release --parallel

    On Windows, put the SDK bin/ directory on PATH before running an example.

    Read docs/USER_GUIDE.md in the archive before running a motion example. Pass the intended RT server IP when more than one robot is on the LAN. With no IP, examples connect to the first discovered robot.

    For offline kinematics, the SDK guide requires a model directory with arm_v2.urdf and its meshes. Obtain the matching model files separately for these two builds.
